# Editor training notes

A half-day session (about three hours) for editors, translators, communications and inbox staff of the
branch office, on the staging site with sample content. Each participant needs a staff account with their
own role and an authenticator app on their phone. The manual is in `docs/manual/` (English and Amharic).

## Before the session

- Accounts created under Users with the right roles and scopes; invitations sent.
- Staging refreshed with the sample content (`php artisan portal:sample-content`).
- A projector, the staging address, and printed copies of manual chapter 2 ("Publishing a post").

## Programme

| Time | Topic | Exercise | Manual |
|---|---|---|---|
| 0:00 | Signing in, two-step sign-in, profile, admin language | Everyone signs in and sets up the authenticator app | 01, §1–2 |
| 0:20 | The dashboard and notifications | Open Notifications; choose "How I am notified" | 01, §2 |
| 0:35 | Writing a post in four languages | Write a short story in Amharic, add English and Afaan Oromo; preview it | 02 |
| 1:05 | Review and publishing | An author submits; an editor sends back with a comment; a publisher publishes and schedules one | 02 |
| 1:25 | Break | | |
| 1:40 | Photos and documents | Upload a photo with alt text in each language; add a document | 01, §5; 03 |
| 2:00 | Events and registrations | Create an event with places; register on the public site; check in by QR code | 03 |
| 2:20 | Messages and tickets | Answer a contact message; assign a ticket to a colleague | 03 |
| 2:35 | Translations and Harari | Find missing strings; export to Excel and import back | 04 |
| 2:50 | Good practice and questions | Privacy, passwords, what never to publish | 01, §8 |

## Target

A participant who has followed chapter 2 publishes a four-language post in under ten minutes
(the project's definition of done). Note each participant's time and any step they found unclear, and
record the session below.
